# 14. Glosario y fuentes

> Pestaña 14 de la *PDR CanSat Universitario – Guía de desarrollo* (Google Docs), migrada al repo el 10/11/2026. Desde la migración se edita acá; ver la sección "La Guía de Drive y el repo" del README.

Siglas que aparecen en la plantilla y en este documento, y las fuentes oficiales. El glosario es la base de la diapositiva de acrónimos (Scoresheet ítem 3); agregar cada sigla nueva que usemos.

## Glosario

| Sigla | Significado | En español |
| --- | --- | --- |
| C&DH | Command and Data Handling | Procesamiento de comandos y datos |
| CDR | Critical Design Review | Revisión crítica de diseño |
| CONOPS | Concept of Operations | Concepto de operaciones |
| EPS | Electrical Power Subsystem | Subsistema de potencia eléctrica |
| FRR | Flight Readiness Review | Revisión de preparación para el vuelo |
| FSW | Flight Software | Software de vuelo |
| GCS | Ground Control Station | Estación terrena |
| GNSS | Global Navigation Satellite System | Sistema global de navegación por satélite (GPS) |
| I&T | Integration and Test | Integración y pruebas |
| IMU | Inertial Measurement Unit | Unidad de medición inercial |
| MOM | Mission Operations Manual | Manual de operaciones de la misión |
| PDR | Preliminary Design Review | Revisión preliminar de diseño |
| PFR | Post-Flight Review | Revisión posterior al vuelo |
| RTC | Real-Time Clock | Reloj de tiempo real |
| SOE | Sequence of Events | Secuencia de eventos |
| TBD / TBR | To Be Determined / To Be Reviewed | Pendiente de definir / de revisar |
